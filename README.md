# Phigros Layout Studio 1.0

**Phigros 曲目排版工作室（PLS）**

用于制作 Phigros 曲目预览图的 Windows 桌面排版编辑器。把曲绘、曲名、曲师、谱师、难度和背景放在同一张可编辑画布上，保存工程、复用模板并批量输出 PNG。

1.0 是首个公开版本。当前材料供发布准备；正式下载、对应源码版本和 SHA-256 以审核后的 Release 为准。仓库源码可供查看，自研部分保留权利，尚未采用开源许可证。

## 功能

| 分类 | 内容 |
| --- | --- |
| 布局 | 三曲、五曲、N 曲网格、单图歌曲卡片；移动、旋转、缩放、对齐、分布与吸附 |
| 图层 | 图片、文字、形状、难度徽标；搜索、筛选、显隐、锁定、编组与排序 |
| 文字与图片 | 本地 TTF / OTF 字体、样式与行距；图片裁切、适配、安全替换及批量导入 |
| 背景与复用 | 纯色、固定和混合背景；布局模板、歌曲角色、歌曲样式与导出预设 |
| 工程 | 自包含 `.ppgproj`、撤销 / 重做、最近工程、自动恢复及资源检查 |
| 输出 | 普通 / 透明 PNG、多宽度队列、跨工程批量、选中内容裁切及命令行输出 |

难度 `EZ` / `HD` / `IN` / `AT` 分别使用绿色、蓝色、红色和黑色；等级为正整数。

## 使用

发布目标为 **Windows 11 25H2 x64**，单屏 100% / 125% / 150% / 200% 缩放。其他平台、混合 DPI 和多屏不在本次正式支持承诺内。已验范围、尚未验证的项目和明确免测项见 [支持与验证边界](docs/public/SUPPORT.md)。

便携包包含运行所需的 .NET 组件。完整解压 ZIP 到普通本地目录，保留全部文件，再运行 `Editor.Desktop.exe`。不要在压缩包内启动或只复制 EXE。

1. 新建工程，使用“添加”菜单生成三曲、五曲或 N 曲布局。
2. 在画布或图层列表选择内容，调整图片、文字、难度与背景。
3. 确认应用属性，再用 `Ctrl+S` 保存 `.ppgproj`。
4. 从“文件 → 导出”输出 PNG。

未应用的字段只是草稿，保存和导出使用已确认的工程内容。工程内嵌所需图片，但只保存字体引用；换电脑时须重新导入同一合法字体。

完整操作见 [使用指南](docs/public/USER_GUIDE.md)；SDK、锁文件、构建和测试命令见 [源码构建说明](docs/public/BUILD.md)。

## 限制

- 每工程最多 200 个图层、200 个资源；新增图片编码总量按内容去重后最多 256 MiB。
- 单张编码图片不超过 100 MiB、8000 万像素或单边 32768 像素。
- PNG 输出最多 8000 万像素，单边不超过 16384 像素。
- TIFF 仅处理受支持的经典 TIFF 首页，不支持 BigTIFF。
- 这些限制不等于全进程内存上限。解码缓存、字体及撤销历史中的旧图片会额外占用内存。

本工具不提供处理任意不可信图片、字体或工程的沙箱保证。请定期备份工程，并检查导出结果。
