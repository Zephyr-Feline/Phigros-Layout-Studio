Phigros Layout Studio 1.0
Phigros 曲目排版工作室（PLS）
Windows 11 25H2 x64 便携发行版

1.0 是本产品的首个公开版本，用于制作 Phigros 曲目预览图。

请完整解压 ZIP 到普通本地文件夹，然后运行 Editor.Desktop.exe。
不要直接在压缩包内运行，也不要只复制 EXE。此包自包含所需运行库。

支持范围

首发目标为 Windows 11 25H2 x64、单屏 100% / 125% / 150% / 200% 缩放。
已验范围与限制见发行页，核心交互通过不等于完整硬件矩阵签收。
混合 DPI、多屏、其他 Windows 版本、ARM64、Linux 和 macOS 不在当前支持承诺内。
官方发行与 SHA-256：https://github.com/Zephyr-Feline/Phigros-Layout-Studio/releases/tag/v1.0.0
第二台干净 Windows 按发布者要求免测，不记为 PASS；实际读屏未专门签收。
可识别的兼容输入仅作只读转换并另存 .ppgproj；可能有外观差异，不支持旧格式写回。

建立第一份工程

1. 使用“文件 → 新建工程”，按需修改画布与背景。
2. 在“添加 → 生成三曲 / 五曲布局”中选择恰好三张或五张本地曲绘。
   其他数量使用“生成 N 曲网格”，图片数量应与行列配置一致。
3. 在画布或图层列表选择图层；拖动移动，使用手柄缩放。
   在所选图层属性中确认修改；难度等级必须是正整数。
4. 使用“编辑 → 歌曲信息工作台”编辑曲绘、曲名、曲师、谱师、难度及角色映射。
5. Ctrl+S 保存 .ppgproj 工程；需要保留备份时使用“工程另存为”。
6. 使用“文件 → 导出”输出普通或透明 PNG；队列支持多种宽度。
   导出所选内容默认保留完整画布；“裁切到选中范围”需要主动勾选。

只保存和导出已确认的内容。属性输入框中未应用的草稿不会因 Ctrl+S 自动提交。
Ctrl+Z 撤销，Ctrl+Y 重做；Ctrl+0 适合窗口，Ctrl+1 实际大小，Ctrl+2 适合所选。
F6 在画布、图层列表、属性与可见标尺之间切换。

工程保存与备份

.ppgproj 工程包含图片、图层、排版和已经确认的编辑内容。
重要修改前可使用“文件 → 工程另存为”保存独立副本。
保存取消或失败后，请按提示重试或另存，不要先删除唯一的工程文件。

字体与换电脑

在所选图层属性中导入有权使用的本地 TTF / OTF 字体。
字体复制到应用本地字体库，不作系统安装；工程只保存引用，不嵌入字体字节。
换电脑时须重新导入同一字体，或主动选择有权使用的替代字体。
字体本身的使用和分发仍须遵守其许可。

资源、历史与文件处理限制

单张图片编码文件不超过 100 MiB；文档新增资源按内容去重后的编码总量不超过 256 MiB。
已存在的超预算工程可以读取、编辑、复用或减少资源，不能继续增长编码资源总量。
这些是文档准入限制，解码像素、字体、撤销/重做保留的旧图片会额外占用内存。
默认历史保留至多 128 条，尚未按唯一资源字节数淘汰；大资源工作时请定期保存。
TIFF 只处理受支持的经典 TIFF 首页；BigTIFF、畸形或超限数据会被拒绝。
应用不提供针对任意不可信文件的沙箱保证。

发行包不含游戏曲绘、用户图片或用户字体。
请只使用自己有权使用的图片、文字和字体。
