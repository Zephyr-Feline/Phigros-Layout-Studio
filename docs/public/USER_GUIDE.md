# Phigros Layout Studio 1.0 使用指南

本指南对应首个公开版本 **Phigros Layout Studio 1.0**（Phigros 曲目排版工作室，简称 PLS）。内容覆盖安装、画布操作、歌曲卡片制作、图层与文字编辑、背景、模板、工程保存和 PNG 输出。

当前材料用于发布准备。正式版本、下载地址与 SHA-256 以审核后的 Release 为准；反馈使用本仓库 Issues，安全问题按 [SECURITY.md](../../SECURITY.md) 私密报告。支持范围与尚未验证的项目见 [支持与验证边界](SUPPORT.md)。

## 1. 安装与启动

### 系统要求

当前发布目标为 Windows 11 25H2 x64。单屏 100%、125%、150% 和 200% 缩放是重点检查范围。

混合 DPI、多屏、其他 Windows 版本、ARM64、Linux 和 macOS 暂不在正式支持承诺内。即使程序能在其他环境中启动，也不代表已经完成相应验收。

### 解压后运行

便携包内已经包含运行所需的 .NET 组件：

1. 解压整个 ZIP 到一个可读写的普通本地文件夹。
2. 保留包内全部文件和子目录。
3. 双击 `Editor.Desktop.exe` 启动。

不要在 ZIP 预览窗口中直接运行，也不要只复制一个 EXE 到别处。缺少同目录运行库、配置和 `notices` 文件时，程序可能无法启动或无法显示完整许可信息。

如果 Windows 对下载文件显示安全提示，请先核对发行方提供的 ZIP SHA-256，再决定是否继续。项目正式发布时会同时提供下载来源和校验值。

### 素材使用权

程序不附带游戏曲绘、用户图片或用户字体。请只导入自己有权使用的图片、文字和字体，并遵守相应素材的授权条件。

## 2. 界面概览

主窗口由顶部菜单、常用工具栏、中央画布、右侧图层与属性区域以及底部状态栏组成。

### 顶部菜单

| 菜单 | 主要用途 |
| --- | --- |
| 文件 | 新建、打开、最近工程、保存、导入工程图层、导出 PNG |
| 编辑 | 撤销 / 重做、复制 / 粘贴、选择命令、文字编辑、歌曲信息、首选项 |
| 添加 | 图片、文字、形状、徽标、歌曲卡片、三曲 / 五曲和 N 曲网格 |
| 图层 | 换图、重命名、显隐、锁定、编组和叠放顺序 |
| 排列 | 相对选中内容或画布进行对齐、等间距排列 |
| 视图 | 缩放、标尺、辅助线、安全区和背景贡献 |
| 模板 | 布局模板、模板库和歌曲样式库 |

常用工具栏只保留高频入口。完整功能仍可从菜单进入。

### 画布与右侧面板

画布用于预览和直接编辑。右侧图层列表用于选择、搜索、排序和快速切换显隐或锁定；下方属性区根据当前选择显示可编辑字段。

图层列表上方显示在前，下方显示在后。选中图层后，画布上的控制点、属性区和菜单操作都针对当前选择。

右侧还有可展开的 **对齐与分布**、**画布与背景**、**布局模板**、**歌曲样式库** 和 **操作提示**。展开区域只影响编辑界面，不会自动修改工程。

### 草稿与已应用内容

属性栏和背景设置中的输入会先成为草稿。只有点击对应的 **应用** 按钮、按单行字段的 Enter，或完成文字编辑对话框后，内容才进入工程。

保存、导出和自动恢复读取的是已应用内容。未应用的数值、文字或背景草稿不会因为 `Ctrl+S` 自动提交。开始导出或关闭工程前，请确认需要的修改已经应用。

## 3. 完成第一张曲目预览图

下面是一条完整的入门流程。

### 3.1 新建工程

选择 **文件 → 新建工程**。默认画布为 2740 × 1080，可以在 **画布与背景** 中修改尺寸、底色和背景，然后点击对应的应用按钮。

画布宽度范围为 320–7680，高度范围为 180–4320。大画布适合高分辨率输出，但会占用更多预览和导出资源。

### 3.2 生成歌曲布局

根据曲目数量选择入口：

- **添加 → 生成三曲 / 五曲布局**：必须选择恰好 3 张或 5 张曲绘。
- **添加 → 生成 N 曲网格**：可设置 1–20 首、行列配置、边距和间距。
- **添加 → 导入图片**：先加入一张图片，再通过 **由图片创建歌曲组** 生成单曲卡片。
- **添加 → 批量导入图片**：只添加普通图片，不会自动生成歌曲组。

三曲、五曲和 N 曲网格会一次创建整批歌曲卡片。读取、校验或数量检查失败时，不会留下半批内容。成功加入后，一次撤销可以移除整批。

### 3.3 调整位置和样式

在画布或图层列表中选中图层：

- 拖动图层内部移动位置。
- 拖动八个白色控制点调整尺寸。
- 拖动上方蓝色控制点旋转。
- 在右侧属性区修改坐标、尺寸、文字、字体、颜色和难度。
- 使用 **排列** 菜单对齐或等间距排列多个对象。

移动和缩放会参考画布、辅助线、其他图层和编组边缘。按住 `Alt` 可以临时关闭吸附。

### 3.4 填写歌曲信息

选中歌曲组后，打开 **编辑 → 歌曲信息工作台**。为每个组确认曲绘、曲名、曲师、谱师和难度对应的图层，再填写实际内容。

使用工作台前，可以先让程序根据已知命名给出角色建议。存在重名、缺项或多个候选时，程序不会替你猜角色，需要在工作台中明确选择。

### 3.5 保存与导出

按 `Ctrl+S` 保存 `.ppgproj`。首次保存会要求选择路径；以后再按 `Ctrl+S` 会保存到当前路径。需要保留独立副本时使用 **文件 → 工程另存为**。

确认页面内容后，从 **文件 → 导出** 选择普通 PNG、透明 PNG 或批量导出。详细选项见 [第 12 节](#12-导出-png)。

## 4. 画布、选择与视图

### 4.1 缩放和平移

- 鼠标滚轮以指针位置为锚点缩放。
- 按住鼠标中键拖动可以平移视图。
- `Ctrl+0` 适合窗口。
- `Ctrl+1` 切换到实际大小 100%。
- `Ctrl+2` 适合当前选择。

工具栏会显示实时缩放百分比。缩放只改变视图，不改变画布尺寸、图层坐标、工程内容或导出的 PNG。

在画布交互未结束时，视图导航命令可能暂时不可用。先松开鼠标或按 `Esc` 结束当前手势。

### 4.2 选择图层

- 单击图层选择它。
- `Ctrl` 单击切换该图层是否加入选择。
- `Shift` 单击把图层追加到现有选择。
- 在画布空白处拖出选框。只有完整位于选框内、可见且未锁定的图层会被选中。
- 在空白处按下 `Ctrl` 或 `Shift` 拖框，可以把结果追加到现有选择。
- 普通空白单击会清除选择，`Esc` 可以取消正在进行的框选。

选择本身不会新增撤销记录，也不会把工程标记为已修改。

### 4.3 整组编辑

右侧 **整组编辑** 控制画布操作是否同时作用于同一歌曲组的其他成员。

开启时，移动或调整组内对象会按组联动；关闭时只操作明确选中的图层。锁定成员不会因为整组编辑而解除锁定。

### 4.4 移动、缩放与旋转

画布获得焦点后，方向键每次微调 1 个单位，按住 `Shift` 时步进 10 个单位。

缩放时按住 `Shift` 可临时保持宽高比。旋转时按住 `Shift` 会按 15° 步进。旋转角度在属性区按 -180° 到 180° 显示和保存。

按住 `Ctrl` 使用控制点时，可以跳过通常会直接触发的缩放或旋转，按普通拖动处理。具体光标提示会说明当前操作。

### 4.5 选择命令

- **编辑 → 取消选择** 清空选择。
- **编辑 → 反向选择** 反转当前可编辑选择；画布或图层列表聚焦时也可按 `Ctrl+Shift+A`。
- 图层筛选开启时，反向选择只考虑筛选结果中可见且未锁定的图层。
- 普通 `Ctrl+A` 在画布或图层列表中选择当前范围内可见且未锁定的内容；文字框内仍执行文字全选。

### 4.6 视图与焦点

`F6` 和 `Shift+F6` 在画布、图层列表、所选图层属性和可见标尺之间循环焦点。属性区会回到上次使用的字段；标尺隐藏时会跳过。

文字框中的输入法组合输入尚未结束时，程序不会截获 `F6`，以免影响中文输入。

## 5. 添加曲目内容

### 5.1 导入图片

**添加 → 导入图片** 支持 PNG、JPEG、BMP 和受支持的 TIFF。导入后，图片默认使用原文件名作为图层名。

**添加 → 批量导入图片** 可以一次选择多张普通图片。图片会按文件选择结果加入，使用轻微错位摆放，不会自动创建歌曲组。整批读取成功后才加入工程，一次撤销可以移除整批。

也可以从资源管理器把本地图片拖到画布。拖放使用与批量导入相同的检查和事务；文件夹、网络路径、缺失文件和非图片项目会被忽略，不会递归扫描目录。

### 5.2 三曲和五曲布局

**添加 → 生成三曲 / 五曲布局** 会按选择的图片数量创建三列或五点布局。每个歌曲组包含曲绘、信息底板、曲名、曲师、谱师和难度徽标。

必须选择恰好 3 张或 5 张曲绘。其他数量会显示错误，当前工程和历史保持不变。

### 5.3 自定义 N 曲网格

**添加 → 生成 N 曲网格** 最多创建 20 首。对话框中可以设置：

- 行数和列数。
- 水平、垂直边距。
- 水平、垂直间距。
- 曲绘文件的选择顺序。

文件按从左到右、从上到下的顺序对应网格槽位。图片数量必须等于网格单元数。全部图片读取成功后才创建整批歌曲组，单个文件失败不会留下部分结果。

### 5.4 单张图片生成歌曲卡片

先导入或选中一张未锁定的图片，再选择 **添加 → 由图片创建歌曲组**。程序会把原图片设为斜切，并添加信息底板、曲名、曲师、谱师和难度徽标。

原图图层 ID、图片数据和缩放方式会保留。一次撤销可以移除新增成员并恢复原图片的编组和斜切状态。

### 5.5 文字、形状和难度徽标

- **添加 → 添加文字** 创建默认文字图层。
- **添加 → 添加形状** 创建独立的半透明底板。
- **添加 → 添加难度徽标** 创建 `EZ`、`HD`、`IN` 或 `AT` 徽标。
- **添加 → 添加 Original 标签** 在选中的歌曲曲绘旁加入白色斜切底板和文字。

Original 标签由两个普通图层组成。选中歌曲组内图片时，标签会加入同一个组；没有选中组内图片时，标签会另行编组。

### 5.6 替换图片

选中图片图层后，可通过 **图层 → 替换图片** 选择新文件。替换会重新校验图片并保留原图层的位置、尺寸、旋转、编组、叠放顺序和其他属性。

替换失败时保留原图片。成功替换属于一次可撤销编辑。

## 6. 歌曲信息与样式复用

### 6.1 歌曲信息工作台

先选中一个或多个歌曲组中的任意成员，再打开 **编辑 → 歌曲信息工作台**。

每个歌曲组需要确认五个角色：

1. 曲绘。
2. 曲名。
3. 曲师。
4. 谱师。
5. 难度徽标。

信息底板可以作为组内成员存在，但不属于必须映射的五个内容角色。确认后，曲名、曲师、谱师、难度和正整数等级会写入对应图层，角色映射也会保存到工程。

工作台支持批量修改多个已选歌曲组，并可统一设置文字字号、颜色和粗体。每个公共样式字段需要单独勾选；未勾选的字段保留各组原值。

组内有锁定成员、角色缺失或重复、角色类型错误、文本非法或替换图片损坏时，整次应用会被拒绝，不会只改一部分。

### 6.2 选择替换曲绘

歌曲信息工作台中的 **替换曲绘** 会在应用时读取并校验新图片。替换后保留曲绘图层 ID、位置、尺寸、旋转、编组和叠放顺序。

只有点击应用并且所有检查通过后，新图片才会进入工程。取消工作台不会修改当前文档。

### 6.3 歌曲样式库

**模板 → 歌曲样式库** 用于复用歌曲卡片的视觉结构。

歌曲样式可以保存：

- 五个角色的结构关系。
- 相对位置和尺寸。
- 字体引用、颜色和其他视觉样式。

歌曲样式不保存曲名、曲师、谱师等正文，不保存图片字节，也不引用源工程的图层 ID。

常用操作：

- **捕获当前歌曲组样式**：从带完整角色映射的组创建样式。
- **应用到选中歌曲组**：保留目标文字、难度和曲绘，只替换几何结构与样式。
- **用选中歌曲内容新建实例**：以当前歌曲内容创建新组。
- **重命名、移除和刷新**：只修改本机样式库，不删除工程图层。

样式库文件保存在 `%LOCALAPPDATA%\PhigrosPreviewEditor\SongStyles`。同名但内容不同的样式会作为不同条目保留，不会静默覆盖。

## 7. 图层管理

### 7.1 图层顺序

图层列表上方显示在前。可用的排序方式：

- 拖动一行到目标位置。目标行上半部表示放在其上方，下半部表示放在其下方。
- 多选拖动时，整体保持选中图层之间的原有相对顺序。
- 列表聚焦后按 `Ctrl+↑` / `Ctrl+↓` 移动当前选择。
- 使用 **图层 → 叠放顺序** 执行前移、后移、置顶或置底。

拖到列表上边缘或下边缘时，列表会随指针移动继续滚动。释放前会显示插入位置。成功排序只新增一次撤销记录；位置没有变化时不会新增历史。

### 7.2 搜索与筛选

图层查找同时匹配图层名称和文字内容：

- 按 Enter 定位下一项，按 `Shift+Enter` 定位上一项。
- **上一项 / 下一项** 按列表顺序移动并滚动到命中行。
- **选中全部匹配项** 选择当前结果中有序、可见且未锁定的图层。
- **仅显示匹配项** 只保留匹配行。

筛选是临时界面状态。开启或修改筛选时，范围外的图层会从当前选择中移除，避免看不见的图层继续随画布操作移动。关闭筛选不会自动恢复之前的选择。

筛选开启时不能拖动列表排序。可以先关闭筛选，或使用键盘和 **叠放顺序** 菜单。

### 7.3 显隐、锁定和重命名

图层行右侧按钮只作用于该行：

- 显示或隐藏图层。
- 锁定或解锁图层。

锁定图层仍可被明确选择、检查和导出，但不能在画布上移动、缩放或旋转。

重命名入口包括 **图层 → 重命名图层**、图层列表 `F2` 和双击图层行。名称会去除首尾空白，不能为空，最长 200 个字符；锁定图层须先解锁。

### 7.4 组概览与组操作

工程存在编组时，右侧会显示可展开的组卡片。卡片标签来自歌曲角色、曲绘或首个成员名称，并显示隐藏和锁定数量。

组卡片支持：

- 选择整组。
- 显示或隐藏整组。
- 锁定或解锁整组。
- 解除编组。
- 展开后对单个成员执行显隐或锁定。

整组命令通常只新增一次撤销记录。锁定成员仍保持不可直接编辑。

### 7.5 复制、粘贴和删除

`Ctrl+C` / `Ctrl+V` 和 **编辑 → 复制选中图层 / 粘贴图层** 可在当前运行的程序内跨工程复制图层。

复制内容包含图层、编组关系、样式、角色和内嵌图片；不包含画布、背景、辅助线、选择历史和瞬时预览。粘贴时使用新的图层、组和资源 ID，并保留图片内容去重。

该剪贴板只存在于当前进程，关闭程序后不会保留，也不会写入 Windows 系统剪贴板供其他应用读取。

`Delete` 或 **编辑 → 删除** 删除当前可编辑选择。删除前不需要二次确认，但可以通过 `Ctrl+Z` 恢复。

### 7.6 跨工程导入与选中内容另存

**文件 → 导入工程图层** 会把另一份 `.ppgproj` 的前景图层按原坐标追加到当前工程，不替换当前画布、背景和保存路径。导入使用新的图层、组和资源 ID，一次撤销可整体移除。

**文件 → 将选中图层保存为工程** 可以把当前选择保存成独立 `.ppgproj`。开启整组编辑时，完整歌曲组会一起保存；关闭时只保存明确选中的图层。新工程沿用画布尺寸和纯色底色，但不会复制当前固定背景或混合背景设置。

## 8. 文字、图片与属性

### 8.1 编辑文字内容

双击未锁定的文字，或选中后使用 **编辑 → 编辑选中文字**，打开多行文字对话框。

- **确定** 会把修改作为一次可撤销编辑提交。
- **取消** 或关闭窗口保留原内容。
- 内容没有变化时不会新增历史。
- 单个文字图层最多保存 4000 个字符。

属性区也能编辑文字内容。多行文字框中的 Enter 用来换行；修改后需要点击 **应用文字** 或使用文字对话框确认。

### 8.2 文字样式

文字图层支持：

- 字体家族。
- 字号。
- 粗体、斜体。
- 颜色。
- 水平对齐：左、中、右。
- 垂直对齐：顶、中、底。
- 行距。

选中两个及以上同类型文字或徽标时，可以展开 **批量样式（多选）**。每个要修改的字段先勾选 **应用**，再填写值。不同图层取值不一致时显示为“多个值”；未勾选的字段保留原值。

批量样式在值非法、目标锁定或选择混有不同类型时会整次拒绝，不会修改部分图层。

### 8.3 导入本地字体

选中文字后，点击 **导入本地字体（TTF / OTF）**。字体文件会复制到本机应用字体库，并注册给当前编辑器使用，但不会安装到 Windows 系统字体目录。

限制：

- 单个字体文件不超过 32 MiB。
- 字体库最多 128 个文件、合计 256 MiB。
- 相同内容的字体按内容去重。

工程只保存字体家族引用，不嵌入字体文件。换电脑或清理本地字体库后，需要重新导入同一字体；缺失时程序会提示并使用替代字体。

字体库位于 `%LOCALAPPDATA%\PhigrosPreviewEditor\Fonts`。字体文件的使用、嵌入和分发条件仍由字体许可证决定。

### 8.4 图层不透明度

所有图层都可以在属性区设置 **不透明度**，范围为 0–100%。它不是选择框或命中区域透明度，而是绘制内容时的最终合成透明度。

文字颜色、形状颜色、图片自身 alpha 和图层不透明度按正常合成规则共同生效。不透明度变化会保存到工程，并可通过撤销恢复。

### 8.5 图片裁切与适配

选中图片后点击 **裁切**，可以设置采样区域和适配方式：

| 适配方式 | 效果 |
| --- | --- |
| 拉伸 | 把采样区域填满图层矩形 |
| 覆盖裁切 | 保持比例填满矩形，多余部分裁掉 |
| 完整适配 | 保持比例显示完整图片，留出透明边 |

采样区域使用图片归一化坐标，范围为 `(0,0)` 到 `(1,1)`。调整裁切不会替换原图资源，也不会改变图层 ID、位置、旋转、编组或叠放顺序。

### 8.6 单行属性应用

名称、位置、尺寸、角度、颜色、字体、字号、行距和难度等级等字段，可以在输入完成后按 Enter 或点击 **应用属性**。

输入法仍在组合候选时，Enter 不会抢先提交。非法输入不会部分修改文档，修正后可以重新提交。

保存前请确认草稿已经应用。只点击应用某个字段，不一定会提交同一属性区中其他尚未应用的修改。

## 9. 背景与资源

### 9.1 纯色背景

在 **画布与背景** 中设置底色，再应用画布设置。透明 PNG 会省略画布纯色背景和背景混合效果，普通 PNG 会包含已应用的纯色背景。

### 9.2 固定背景

固定背景是一张覆盖整个画布的图片。程序按画布比例使用中心覆盖裁切。已有固定背景时，它优先于自动混合背景。

固定背景会随 `.ppgproj` 一起保存。清除固定背景不会立即删除图片资源；之后可通过资源清理功能回收未引用内容。

### 9.3 自动混合背景

开启混合背景后，程序可以使用多张可见曲绘生成柔和的背景合成效果。可在 **视图 → 背景贡献** 中调整：

- 自动使用全部合格曲绘，或只使用明确勾选的图片。
- 是否包含非斜切平面图片。
- 颜色的扩散范围。
- 边缘过渡的柔和度。
- 背景压暗程度和模糊半径。

自动模式默认使用可见斜切曲绘。手动选择模式只使用勾选、可见且不透明度大于 0 的图片。

背景贡献设置会保存到工程，并通过一次撤销整体恢复。透明导出不包含固定背景或自动混合背景。

### 9.4 资源与质量检查

**编辑 → 资源与质量检查** 可以查看工程内嵌图片的尺寸、编码大小、内容哈希和引用图层。

可执行的操作：

- **定位引用**：选择当前引用某个资源的全部图层。
- **安全替换**：校验新图片后，替换所有引用该资源的图层和固定背景。
- **清理未引用资源**：删除没有当前图层或固定背景引用的图片。

隐藏或锁定图层仍然拥有资源，不会被清理误删。清理未引用资源不会压缩或重新编码仍被使用的图片，并可通过撤销恢复。

程序不会因为图片较大就自动压缩。若希望减小工程体积，请先自行生成尺寸合适、授权明确的替代图片，再使用安全替换。

## 10. 对齐、模板与辅助线

### 10.1 对齐与等间距

选择多个对象后，使用 **排列**：

- 左对齐、水平居中、右对齐。
- 顶对齐、垂直居中、底对齐。
- 水平等间距、垂直等间距。

参照对象可以是选中内容整体外框，也可以是画布。等间距通常至少需要三个独立对象。

右侧 **对齐与分布** 提供相同操作。整组编辑开启时按组参与排列，关闭时只处理明确选中的图层。

### 10.2 布局模板

布局模板记录一组可复用槽位的位置和尺寸，扩展名为 `.ppglayout`。

常用流程：

1. 选择用于定义布局的图层或歌曲组。
2. 使用 **模板 → 捕获选中内容的布局**。
3. 使用 **模板 → 保存布局模板** 导出独立文件。
4. 在另一份工程中通过 **模板 → 打开布局模板** 读取并应用。

布局模板只保存槽位，不保存歌曲正文和图片。应用时，目标内容会按槽位重新定位和缩放；过小的槽位或无法完成的操作会整次拒绝。

### 10.3 本地模板库

右侧 **布局模板 → 本地模板库** 可以在多次启动之间保存模板：

- 把当前模板加入库。
- 从 `.ppglayout` 文件导入到库。
- 查看槽位预览并应用。
- 重命名、导出或移除库内条目。

模板库位于 `%LOCALAPPDATA%\PhigrosPreviewEditor\LayoutTemplates`。同名且内容相同的条目不会重复保存；同名但内容不同的模板会分别保留。

### 10.4 标尺和辅助线

顶部和左侧标尺可以显示当前画布坐标。从标尺向画布拖动可创建水平或垂直辅助线。

- 拖动辅助线调整位置。
- 把辅助线拖回标尺，或在悬停时按 `Delete`，可以删除。
- **视图 → 在中心添加垂直 / 水平辅助线** 可快速放置中心线。
- **视图 → 清除辅助线** 会移除当前会话的全部手动辅助线。

辅助线属于当前编辑会话，不写入工程或 PNG。新建、打开或导入工程时会清空；普通撤销 / 重做不会清除。

### 10.5 安全区

在 **编辑 → 首选项** 中可以启用安全区并设置 0–20% 的边距。安全区按画布短边统一内缩，只作为预览参考，不会进入导出的 PNG。

安全区显示时，其四条边会参与移动和缩放吸附。**视图 → 按安全区添加辅助线** 可以把四边转换成普通会话辅助线，重复执行不会重复添加。

## 11. 保存、恢复与文件

### 11.1 保存工程

- `Ctrl+S`：保存到当前 `.ppgproj`；没有路径时打开保存窗口。
- `Ctrl+Shift+S`：始终执行工程另存为。
- 标题末尾的 `*` 表示存在尚未保存的已应用修改。

保存使用原子写入。保存成功后，同一选择下的属性草稿仍会保留，直到你应用或切换选择；保存不会替你提交草稿，也不会新增撤销记录。

取消保存窗口或保存失败时，当前工程保持可编辑。请不要先删除唯一的工程副本，按提示重试或另存到其他位置。

### 11.2 工程内容

`.ppgproj` 是一个自包含工程包，包含：

- 画布尺寸和底色。
- 全部图层、文字、样式和编组。
- 歌曲角色和背景贡献设置。
- 图层及固定背景使用的图片资源。

工程不包含本地字体文件、窗口选择、撤销历史、辅助线、缩放位置或未应用的草稿。

### 11.3 最近工程

**文件 → 最近工程** 记录成功打开或保存的 `.ppgproj`，最多保留 12 项。

文件已移动或删除时，菜单会将该条目标记为不可用。**清理缺失项** 只移除最近工程索引，不会删除磁盘上的任何用户文件。

### 11.4 自动恢复

工程有未保存修改时，程序大约每 15 秒在空闲状态生成恢复快照。快照只在没有文件操作和画布手势时创建。

下次启动若发现恢复快照，可以：

- **恢复为未保存工程**。
- **丢弃选中快照**。
- **稍后处理**。

恢复后的内容不会自动覆盖原工程。检查结果后，请另存为新的 `.ppgproj`。

自动恢复只包含已经应用的工程内容，不包含属性草稿、撤销历史、选择、视图缩放或面板状态。恢复文件保存在 `%LOCALAPPDATA%\PhigrosPreviewEditor\Recovery`，有数量、容量和保留时间限制。

### 11.5 打开兼容工程

打开某些可识别的兼容工程来源时，程序会把内容导入为一份未保存的当前工程。原文件不会被改写；请检查文字、图片、裁切、显隐和背景，再另存为 `.ppgproj`。

转换提示会列出无法完全保留或可能与原渲染外观不同的部分。需要继续使用原文件时，请保留原件和能够打开它的软件。

### 11.6 临时 JSON

**文件 → 其他格式 → 保存临时 JSON** 用于诊断和交换，不是推荐的日常工程格式。保存临时 JSON 后会清除当前 `.ppgproj` 保存目标，下一次原生保存需要重新选择路径。

正常制作请使用 `.ppgproj`。临时 JSON 不保证提供与原生工程包相同的资源封装和长期兼容保障。

## 12. 导出 PNG

### 12.1 普通与透明 PNG

从 **文件 → 导出 → 导出 PNG / 导出透明 PNG** 开始。

普通 PNG 包含画布底色以及已启用的固定或混合背景。透明 PNG 省略这些背景；普通图层仍按自身的可见性和透明度绘制。

导出前会检查隐藏图层、超出画布的内容、缺失字体和低分辨率素材等问题。警告通常允许你确认后继续。关闭提示窗口视为取消导出。

### 12.2 输出尺寸

PNG 尺寸窗口默认使用画布大小。也可以输入输出宽度，程序按当前画布或裁切范围的比例计算高度。

限制：

- 宽和高均不超过 16384 像素。
- 总像素数不超过 8000 万。
- 输出高度按整数像素取整，错误只影响光栅边界，不改变工程中的逻辑坐标。

低分辨率提示表示源图片在当前输出尺寸下会被放大。可以降低输出宽度、更换更高分辨率素材，或明确接受提示继续。

### 12.3 批量导出当前工程

**文件 → 导出 → 批量导出 PNG** 可以在同一个工程上配置多个“宽度 + 普通 / 透明”任务。

在窗口中可以：

- 添加、移除和去重任务。
- 查看每个任务的实际尺寸和文件名。
- 查看指定宽度下的素材放大提示。
- 保存或应用导出预设。
- 选择本次使用“仅提示”还是“发现放大提示时阻止导出”。

选择输出父目录后，程序会创建带日期和时间的独立子目录。任务按顺序执行；取消或某个任务失败时，已经完成的 PNG 会保留，当前文件不会留下半张图。

导出结果会写入 `export-manifest.json`。清单记录任务、状态、警告和本次质量策略，便于核对输出。

### 12.4 导出选中内容

**文件 → 导出 → 批量导出选中内容** 只输出当前选择。

默认仍使用完整画布。勾选 **裁切到选中范围** 后，程序根据选中图层的旋转后可视边界计算裁切矩形，并与画布相交。

- 开启整组编辑时，隐藏和锁定成员也参与范围计算。
- 隐藏成员只贡献边界，不会绘制。
- 普通模式绘制画布底色；透明模式省略底色。
- 固定背景和自动混合背景不会并入选中内容。
- 裁切只影响本次输出，不修改工程、预设或图层。

如果切换裁切模式会让已有任务超过尺寸或像素限制，程序会恢复原模式并提示先调整宽度。

### 12.5 跨工程批量导出

**文件 → 导出 → 跨工程批量导出** 可以一次选择多个 `.ppgproj`，使用统一任务配置输出 PNG。

每份工程会独立读取、校验和渲染，不会切换当前正在编辑的工程。某份工程损坏或被质量策略阻止时，其他工程仍可继续。

输出目录使用自动创建的独立子目录，单文件写入是原子的，但多个文件不构成一个整体事务。执行结束后写入 `project-render-manifest.json`，逐工程、逐任务记录结果和警告。

### 12.6 导出预设

批量导出窗口支持保存和执行预设。预设包含输出宽度、透明模式和默认质量策略，不包含工程、输出目录、图片或文字内容。

同一预设库可用于当前工程队列和跨工程批量窗口。应用预设会替换任务列表和质量策略，但保留已经选择的输出父目录或工程列表。

预设保存在本机用户目录，版本不兼容或文件损坏时会回退为空列表，不会覆盖原文件。

### 12.7 命令行输出

已解压的便携包可以用 CLI 输出 PNG：

```powershell
.\Editor.Desktop.exe --render `
  .\song.ppgproj `
  .\song.png `
  --width 2560
```

可选参数：

| 参数 | 作用 |
| --- | --- |
| `--transparent` | 输出透明背景 |
| `--width <pixels>` | 指定输出宽度，高度按比例计算 |
| `--crop <x,y,width,height>` | 使用画布逻辑坐标裁切输出 |
| `--block-low-resolution` | 存在素材放大警告时阻止输出 |

跨工程输出使用：

```powershell
.\Editor.Desktop.exe --render-batch .\batch-plan.json
```

计划文件包含 `outputParent`、`projects` 和 `tasks`。任务字段包括 `width` 和 `transparent`。带 `qualityPolicy` 的计划使用版本 2；版本 1 不允许该字段。

退出码：

- `0`：全部成功。
- `1`：读取、渲染、写入或质量策略失败。
- `2`：参数、计划字段或语法错误。

命令行输出同样不会改写输入工程。正式自动化前，请先在小尺寸上检查文件名、路径和退出码。

## 14. 限制与常见问题

| 项目 | 限制 |

| 画布 | 320–7680 × 180–4320 |

| 资源 | 每工程最多 200 个；新增编码总量最多 256 MiB，按内容去重 |
| 单张图片 | 编码不超过 100 MiB；不超过 8000 万像素；单边不超过 32768 |
| PNG | 单边不超过 16384；最多 8000 万像素 |
| 文字 | 每层最多 4000 个字符 |
| 图层名 | 最多 200 个字符 |
| 本地字体 | 单个 32 MiB；最多 128 个、合计 256 MiB |
| 撤销历史 | 默认最多 128 条 |

这些是工程准入和输出限制，不等于进程整体内存上限。大图、撤销历史、解码缓存和背景混合会同时占用内存。

### 14.2 修改没有保存

最常见的原因是字段仍处于草稿状态。检查属性区是否已经点击 **应用属性**，文字是否通过对话框确认，背景和画布设置是否点击了各自的应用按钮。

只输入数值而不应用，保存、导出和自动恢复都不会包含该输入。

### 14.3 无法移动或修改图层

检查图层是否锁定。锁定图层可以显隐、排序和检查资源，但不能在画布上直接编辑。需要先解锁，或通过允许编辑锁定成员的专用命令处理。

如果开启了图层筛选，范围外图层也会从当前选择中移除。关闭筛选并重新选择所需图层。

### 14.4 字体显示不一致

工程只保存字体引用。请确认本机已经导入同一字体，并检查字体家族、粗体和斜体文件是否齐全。

换电脑后，如果只复制 `.ppgproj`，工程中的文字会保留引用，但可能使用替代字体显示。导入原字体后重新打开或应用文字样式。

### 14.5 导出提示低分辨率

提示表示某个可见图片在当前输出尺寸下的可用像素不足以覆盖显示区域。可以：

- 减小输出宽度。
- 使用更高分辨率的曲绘。
- 调整图片裁切，减少放大区域。
- 明确接受提示继续。
- 在本次批量导出中选择阻止低分辨率输出。

提示不会自动修改图片、裁切或图层尺寸。

### 14.6 导出失败或没有生成文件

检查：

- 输出文件夹是否存在写权限。
- 输出路径是否仍连接且可用。
- 目标 PNG 是否被其他程序占用。
- 输出宽度和高度是否超过限制。
- 工程中是否有损坏或缺失的图片、字体引用。

批量输出会保留已经成功的文件，并在清单中记录失败项。修复路径或资源后，可以重新选择输出目录执行。

### 14.7 工程打开失败

请先确认文件扩展名是 `.ppgproj`，并确认文件来自完整保存或复制的工程，而不是尚未完成的下载、云盘占位文件或手工改名的其他数据。

如果程序报告工程版本、资源哈希或结构错误，请保留原文件，不要覆盖它。可以尝试从最近工程、自动恢复快照或备份副本打开。

### 14.8 界面缩放或布局异常

当前重点支持单屏常规缩放。如果窗口控件在非常规 DPI、多屏或远程桌面环境中出现错位，请记录 Windows 版本、缩放比例、显示器和远程会话配置。

在启动前把主显示器缩放调整为 100%、125%、150% 或 200%，有助于判断是否为屏幕 DPI 组合问题。

### 14.9 大工程运行较慢

200 图层、超大画布、透明图片、混合背景和较深的撤销历史都会增加内存和渲染开销。建议：

- 定期保存并关闭不再需要的历史分支。
- 避免导入远超实际输出尺寸的图片。
- 完成大工程后使用资源检查寻找未引用图片。
- 批量导出前先用小尺寸验证任务配置。

不要为了节省空间直接删除工程内仍被引用的资源。使用安全替换或资源清理功能。

## 15. 素材、隐私与反馈

### 15.1 素材与字体

图片、文字和字体可能受版权、署名或其他许可条件约束。项目不附带游戏曲绘、用户图片或用户字体，也不改变这些素材的授权状态。程序通过 Avalonia.Fonts.Inter 内置的 Inter 字体另适用随包提供的 SIL OFL 许可。

使用本地字体不会把字体安装到系统，但导出图片中仍会显示字体字形。将成图用于公开渠道前，请确认字体许可允许相应用途。

### 15.2 工程分享

`.ppgproj` 包含工程内嵌图片。分享工程前，请确认图片、文字、曲名和作者信息都适合交给接收者。

`export-manifest.json` 和 `project-render-manifest.json` 记录输出任务、状态、质量策略和警告。它们可能包含工程文件名和图层名，公开分享结果目录前请检查。

### 15.3 本地数据

以下数据保存在本机应用数据目录，不会随 `.ppgproj` 自动迁移：

- 本地字体库。
- 最近工程列表。
- 自动恢复快照。
- 布局模板库。
- 歌曲样式库。
- 导出预设和用户首选项。

清理应用数据前请备份需要的模板、样式和工程。删除本地库不等于删除已经保存到工程中的正文或图片，但可能让工程缺少可复现的字体。

### 15.4 报告问题

普通问题请使用本仓库 **Issues → New issue**。安全问题请按 [SECURITY.md](../../SECURITY.md) 私密报告。提交问题时，建议附上：

- 产品版本 `1.0`。
- Windows 版本和系统架构。
- 屏幕分辨率、缩放比例及是否使用多屏或远程桌面。
- 问题发生在导入、编辑、保存、重开还是导出阶段。
- 可以稳定重复的步骤、预期结果和实际结果。
- 完整错误文字或截图。

提供最小工程或图片前，请先检查隐私、文件路径和素材使用权。不要上传无权公开的游戏曲绘、字体文件或个人工程。
