# 支持与验证边界

此表是 Phigros Layout Studio 1.0（PLS）的发布准备说明。最终发行身份及相应结果应在审核后的 Release 中绑定；此前候选的检查保持原身份，不自动算作新包的实测。

## 平台与功能范围

- 首发目标：Windows 11 25H2 x64，单屏 100% / 125% / 150% / 200% 缩放，完整解压的自包含便携包。
- 主要工程格式：`.ppgproj`，保存画布、图层、文字、角色和内嵌图片；不嵌入用户字体。
- 输出：普通 / 透明 PNG、选中内容裁切、同工程多宽度及跨工程队列、CLI 渲染。
- 混合 DPI、多屏、其他 Windows 版本、ARM64、Linux 和 macOS 不在本次正式支持承诺内；能启动不代表验收完成。

## 现有检查的准确范围

| 项目 | 已有依据与边界 |
| --- | --- |
| 制作、保存、重开和输出 | 已有本机三曲、五曲、N 曲制作及工程重开、普通 / 透明 / 裁切输出记录；不同记录归属其实际候选，不能视作每个后续包重做了全套 |
| 显示与输入 | 四档缩放的核心交互和代表样例普通 GUI PNG 对照、Microsoft Pinyin 及焦点导航已有记录；不扩张为所有缩放 / 输入法 / 活动手势组合 |
| 侧栏修复 | 已在实际候选检查 25 层工程、搜索、独立滚动条、选择摘要、属性换行对齐和提示位置；不要求重复此前整套人工操作 |
| 自动化与便携运行 | 有自动测试、兼容解析、受限 PATH / 隔离用户配置、字体持久化和 PNG 检查；不等同于第二台干净 Windows 或实际读屏 |
| 稳定性 | 有有界 GUI 观察及大资源探针；不是连续监控、长期无泄漏或普遍性能保证 |

## 未验证或有限验证

- 实际读屏软件的播报可理解性尚未专门签收，不纳入本次核心最低验收；UIA 属性和键盘导航不代替听取检查。
- Explorer 混合拖入、长列表连续边缘拖排、按住手势取消 / 捕获 / 窗口变化没有从用户的整体反馈中推断逐项 PASS。已有自动化和部分实机观察仍各保留边界，本轮不要求用户重跑历史操作清单。
- 混合 DPI / 多屏、其他输入法以及全部活动手势组合未完整验证。
- 未完成独立发布者签名 / 完整证书链认证；最终包是否签名应由发行说明明确，不应把哈希当作签名。
- 公共 Windows CI 和 CodeQL 的结果应以新仓库实际运行记录为准；配置文件的存在不构成成功扫描。

## 明确免测

第二台干净 Windows 的检查按发布者要求免测。开发机上的隔离配置与受限 PATH 验证不改写为干净系统 PASS。

## 兼容输入范围

支持的兼容工程会导入为当前未保存工程，原件不被改写；检查提示后另存 `.ppgproj`。没有旧格式写回能力，也不承诺逐像素复刻其他渲染器。徽标形状、文字度量 / 换行、背景渐变等可能出现转换偏差；最终首发是否接受该范围仍需发布者确认。

原件和可打开它的软件应自行保留。兼容读取实现保留于源码，不构成对相关第三方软件或旧产品的再分发。
